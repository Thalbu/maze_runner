# Exercício computacional 1

O primeiro exercicio foi feito usando Rust e NodeJS e a abaixo tem-se o passo a passo para rodar. Para rodar o programa deve ter o NodeJS instalado, indicação que seja o 18.X.X. e em Rust também é necessário instalar o compilador

### Passo a passo para rodar com NodeJS:

1- Entrar na pasta `scr` pelo terminal

2- Com NodeJS: rodar o comando `node exercicio-computacional-1.js`

### Passo a passo para rodar com Rust:

1- Entrar na pasta `scr` pelo terminal

2- Rodar o comando `rustc ./main.rs`

3- Rodar o comando `./main`

# Exercício computacional 2

Nesse foi decidido usar C++, pois seria a linguagem usada na disciplina e seria mais tranquilo de receber apoio em dúvidas no próprio exercício.

### Passo a passo para rodar:

1- Entrar na pasta `scr` pelo terminal
